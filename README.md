# Nexa — Digital Solutions Website

A modern responsive static website built as part of my Codveda Technology internship.

## 🚀 Project Overview

Nexa is a fictional digital solutions agency website designed to demonstrate fundamental frontend development skills using HTML and CSS.

The website focuses on creating a clean, modern, responsive, and user-friendly experience.

## 📄 Pages

- Home
- About
- Contact

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Media Queries
- Responsive Web Design

## ✨ Features

- Responsive navigation
- Modern hero section
- Services section
- About section
- Company values
- Contact information
- Contact form
- Responsive layouts
- Hover effects
- Gradient visual elements
- Mobile-friendly design

## 📱 Responsive Design

The website has been designed to work across:

- Desktop
- Tablet
- Mobile

CSS media queries are used to adapt layouts, typography, cards, forms, and spacing to different screen sizes.
